# ProyectoRutinas

## Descripción

Proyecto desarrollado como parte de la asignatura de programación utilizando el patrón de arquitectura ASP.NET MVC (.NET Framework).

La aplicación tiene como objetivo proporcionar una plataforma donde los usuarios puedan explorar una rutina de entrenamiento, registrarse, iniciar sesión y administrar la información de su cuenta mediante un CRUD de usuario.

El proyecto está diseñado como un prototipo funcional, priorizando una arquitectura organizada, escalable y fácil de mantener.

---

# Objetivos

- Implementar una aplicación web utilizando ASP.NET MVC.
- Aplicar el patrón Modelo - Vista - Controlador (MVC).
- Implementar un sistema de registro e inicio de sesión.
- Desarrollar un CRUD para la administración del perfil del usuario.
- Aplicar buenas prácticas de organización y documentación del proyecto.
- Utilizar Git y GitHub como herramienta de control de versiones.
